# Release v0.3.0 - Unified Intelligence Dashboard & CRM Logging

## Core Features
*   **Unified Dashboard Redesign**: Restructured the hub configuration interface into a seamless, single-page grid. Highly valuable tools like the Simulation Engine and Interaction Logs are now prioritized and always visible alongside dynamic configuration parameters.
*   **Persistent Interaction Tracking (CRM)**: Transitioned from stateless outputs to persistent conversational data. A new `sirens.db` SQLite tracking system logs timestamps, extracted visual customer attributes, and the exact VLM outputs generated by the agent.
*   **Live Analytics Feed**: Pushed interaction states are immediately viewable within the Hub interface to measure the quality of cold-opens against configured psychological boundaries.

## Testing & Quality Assurance
*   **E2E Integration Validation**: Pushed full end-to-end simulated interaction tokenizing using a lightweight `MockRedis` class to ensure SSE chunking operates without requiring a full live server deployment.
