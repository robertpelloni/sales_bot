# Project Sirens - REST API Documentation

The Project Sirens Hub exposes RESTful endpoints for configuration, lead tracking, simulations, and server lifecycle operations.

## Base URL
`http://localhost:8000`

## Authentication
Configuration and administration endpoints are protected with HTTP Basic Authentication.
- Default Username: `admin` (configurable via `ADMIN_USER` environment variable)
- Default Password: `password` (configurable via `ADMIN_PASS` environment variable)

---

## Endpoints

### 1. `GET /`
- **Description**: Renders the unified single-page operations and intelligence dashboard.
- **Response**: HTML template containing live status indicators, simulation engine, CRM feed, visual charts, inventory management, and psychology modifier forms.

### 2. `GET /api/status`
- **Description**: Returns real-time health, server version, vision mode, and configuration metrics.
- **Response**:
```json
{
  "status": "healthy",
  "service": "Project Sirens Hub",
  "version": "0.8.0",
  "mock_vision": true,
  "camera_index": "0",
  "has_openai_key": false,
  "inventory_item_count": 3
}
```

### 3. `WebSocket /ws/events`
- **Description**: Real-time duplex WebSocket stream. On connection, clients receive live push events broadcast whenever new customer interactions are captured or logged.
- **Message Type**: JSON
- **Payload Schema**:
```json
{
  "type": "new_interaction",
  "data": {
    "id": 105,
    "detected_attributes": "navy blue windbreaker, baseball cap",
    "dialogue": "Handcrafted windbreakers on special today!",
    "strategy": "Pattern Interrupt",
    "timestamp": "2026-11-05 05:00:00",
    "tts_latency": "115ms",
    "is_lead": false,
    "rating": 1,
    "follow_up": null
  }
}
```

### 3. `POST /api/server/shutdown`
- **Description**: Gracefully terminates the Hub server process after acknowledging the request.
- **Response**:
```json
{
  "status": "shutting_down",
  "message": "Hub server is shutting down gracefully."
}
```

### 4. `POST /api/log_interaction`
- **Description**: Ingests customer interaction events from the edge VLM pipeline into the persistent SQLite database (`sirens.db`).
- **Request Body**:
```json
{
  "attributes": "black jacket, blue sneakers",
  "response": "Cold open pitch generated by LLM.",
  "sales_framework": "Pattern Interrupt",
  "tts_latency_ms": 142
}
```
- **Response**:
```json
{
  "status": "success",
  "id": 104
}
```

### 5. `POST /simulate_detection`
- **Description**: Simulates a visual detection event and returns the generated VLM response without requiring physical camera hardware.
- **Form Parameters**:
  - `attributes`: Comma-separated visual traits.
  - `system_prompt_override`: (Optional) Temporary prompt bypass for A/B testing.
  - `temperature`: Creativity slider (0.0 to 1.5).

### 6. `POST /mark_lead/{interaction_id}`
- **Description**: Flags or unflags a specific customer interaction as a qualified CRM lead.
- **Form Parameter**: `is_lead` (`"True"` or `"False"`).

### 7. `POST /submit_feedback/{interaction_id}`
- **Description**: Submits staff feedback ratings (thumbs up/down) for pitch quality tuning.
- **Form Parameter**: `feedback_score` (`1` or `5`).

### 8. `POST /update_follow_up/{interaction_id}`
- **Description**: Appends permanent staff follow-up notes to a CRM interaction record.
- **Form Parameter**: `follow_up_notes`.

### 9. `GET /api/ab/allocations`
- **Description**: Retrieves real-time Multi-Armed Bandit framework allocation metrics, Bayesian priors, win rates, and trial counts.
- **Query Parameter**: `method` (`thompson` or `epsilon_greedy`, default: `thompson`).
- **Response**:
```json
{
  "method": "thompson",
  "recommended_framework": "Challenger Sales Framework",
  "arms": {
    "Challenger Sales Framework": {
      "trials": 15,
      "leads": 6,
      "win_rate": 0.4,
      "feedback_sum": 4,
      "alpha": 7.0,
      "beta": 10.0
    }
  }
}
```

### 10. `POST /api/ab/select_framework`
- **Description**: Dynamically requests the bandit algorithm to allocate a sales framework for an incoming customer interaction.
- **Query Parameter**: `method` (`thompson` or `epsilon_greedy`, default: `thompson`).
- **Response**:
```json
{
  "framework": "Challenger Sales Framework",
  "method": "thompson",
  "trials": 15,
  "win_rate": 0.4
}
```
